 Task 1 — BMI Calculator

This is a Python GUI-based BMI Calculator that calculates Body Mass Index using height and weight inputs.  
It shows the BMI value, category (Underweight, Normal, Overweight, Obese), saves results, and displays a graph.

Run:
pip install matplotlib  
python bmi.py

 Files:
bmi.py — main program  
bmi_history.csv — saved data
