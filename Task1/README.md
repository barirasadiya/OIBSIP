 Task 1 — BMI Calculator
 
Objective:
Build a Python GUI app to calculate Body Mass Index (BMI) and display health category.

Steps Performed:
- Created interface using Tkinter
- Took height and weight input
- Calculated BMI using formula
- Classified result (Underweight, Normal, Overweight, Obese)
- Displayed result
- Saved data to CSV file

Tools Used:
Python, Tkinter, VS Code

Outcome:
A working BMI Calculator that computes BMI instantly, shows health status, and stores records.
