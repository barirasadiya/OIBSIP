Task 2 – Password Generator
A Python GUI app that generates secure passwords with customizable options like length, characters, numbers, and symbols.

Features:
- Select password length
- Include/exclude:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Symbols
- Option to exclude specific characters
- Copy generated password to clipboard
- Simple and user-friendly GUI
  
Tech Used
Python, Tkinter

Run:
python password.py
